Ordena las oraciones para construir un párrafo con sentido.

  • Cinco retos, sin límite de tiempo.
  • Arrastra las tarjetas, usa las flechas o selecciona dos para intercambiarlas.
  • Puedes comprobar, corregir y reiniciar cada reto.
  • Si necesitas avanzar, pulsa «Siguiente reto».
