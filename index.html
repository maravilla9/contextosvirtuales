Las oraciones llegaron revueltas. Ordénalas para construir un párrafo con sentido.

  • Cinco retos, sin límite de tiempo.
  • Arrastra una oración a su posición, usa las flechas o selecciona dos tarjetas para intercambiarlas.
  • Puedes corregir, pedir una pista o reiniciar el reto.
  • Puedes avanzar aunque no aciertes: primero verás la solución.

Coloca primero la idea inicial. Después ordena el desarrollo y el cierre.
